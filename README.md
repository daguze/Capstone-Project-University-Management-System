University Management System (Django)

-A simple yet functional Django web application designed to manage university data, including students, staff, and grades.  
 The system allows admins to manage users, staff to view and edit grades, and students to access their information.

- When i start this project was mainly to solve the manual paper system in my country in many universities and there are a log lines tiring days just to look at results

Features

- Custom user authentication (Admin, Staff, Student)
- Admin dashboard with user management
- Staff panel for viewing and editing student grades
- Student profile and course overview
- REST API access for system data
- Search and ordering features for student lists
- Responsive HTML templates styled with Bootstrap

Technologies Used

- Python
- Django 
- Django REST Framework  
- SQLite 
- HTML, Bootstrap
